## 👨‍💻 Sobre mim

Sou **Desenvolvedor de Software**, formado em **Análise e Desenvolvimento de Sistemas**, com experiência no desenvolvimento e manutenção de aplicações corporativas.

Minha principal área de atuação é o ecossistema **Java**, trabalhando com aplicações back-end, integrações, APIs, bancos de dados relacionais e desenvolvimento web.

Também gosto de transformar ideias em produtos reais, explorando arquitetura, automação, experiência do usuário e soluções Full Stack.

- ☕ Java e Spring Boot
- 🔗 APIs REST e integrações entre sistemas
- 🗄️ Oracle, SQL Server e PostgreSQL
- 🌐 Desenvolvimento Full Stack
- ⚙️ Maven, Hibernate/JPA e Git
- 🖥️ HTML, CSS, JavaScript, Bootstrap e Angular
- 🏗️ Interesse em arquitetura de software e boas práticas
- 🚀 Desenvolvimento de projetos próprios e produtos digitais
